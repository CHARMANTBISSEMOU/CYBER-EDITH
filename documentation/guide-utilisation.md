## Première Connexion

### Étape 1 : Inscription
1. Ouvrez l'application
2. Appuyez sur **"S'inscrire"**
3. Remplissez le formulaire :
   - **Nom complet** : Votre nom et prénom
   - **Email** : Une adresse email valide
   - **Téléphone** : Votre numéro de téléphone
   - **Mot de passe** : Minimum 8 caractères
4. Appuyez sur **"Créer mon compte"**
5. Vérifiez votre email pour confirmer l'inscription

### Étape 2 : Connexion
1. Sur l'écran d'accueil, entrez votre **email** et **mot de passe**
2. Appuyez sur **"Se connecter"**
3. Laissez l'application charger votre profil

## Gestion des Biens Immobiliers

### Ajouter un Bien

1. **Accéder à la section** :
   - Appuyez sur **"Mes Biens"** dans le menu
   - Appuyez sur le bouton **"+"** (ajouter)

2. **Remplir les informations** :
   - **Type de bien** : Maison, Appartement, Terrain, Bureau...
   - **Titre** : Nom attractif pour votre annonce
   - **Description** : Détails complets du bien
   - **Prix** : Montant en FCFA ou devise locale
   - **Localisation** : Adresse ou position GPS
   - **Superficie** : Surface en m²
   - **Nombre de pièces** : Chambres, salles de bain...

3. **Ajouter des photos** :
   - Appuyez sur **"Ajouter des photos"**
   - Prenez des photos directement ou choisissez dans la galerie
   - Ajoutez jusqu'à 10 photos maximum

4. **Publication** :
   - Vérifiez toutes les informations
   - Appuyez sur **"Publier le bien"**
   - Votre annonce sera visible par les autres utilisateurs

### Modifier un Bien

1. **Sélectionner le bien** à modifier dans "Mes Biens"
2. Appuyez sur l'icône **✏️** (modifier)
3. Apportez les changements nécessaires
4. Appuyez sur **"Sauvegarder les modifications"**

### Supprimer un Bien

1. **Sélectionner le bien** à supprimer
2. Appuyez sur l'icône **🗑️** (supprimer)
3. Confirmez la suppression dans la fenêtre de dialogue

## Recherche de Biens

### Recherche Simple

1. **Accéder à la recherche** :
   - Appuyez sur **"Rechercher"** dans le menu principal

2. **Critères de recherche** :
   - **Type de bien** : Filtrez par catégorie
   - **Localisation** : Ville, quartier ou région
   - **Fourchette de prix** : Prix minimum et maximum
   - **Superficie** : Surface souhaitée

3. **Lancer la recherche** :
   - Appuyez sur **"Rechercher"**
   - Les résultats s'affichent par ordre de pertinence

### Recherche Avancée

1. Appuyez sur **"Filtres avancés"**
2. Affinez votre recherche avec :
   - **Nombre de pièces** exact
   - **Équipements** : Garage, piscine, climatisation...
   - **Date de publication** : Biens récents uniquement
   - **Statut** : Disponible, sous offre, vendu...

### Résultats de Recherche

Pour chaque bien trouvé :
- **📷 Photos** : Galerie d'images du bien
- **📍 Carte** : Position géographique
- **💰 Prix** : Montant et conditions
- **📞 Contact** : Informations du propriétaire
- **❤️ Favoris** : Ajouter à vos favoris

## Géolocalisation et GPS

### Activer le GPS

1. **Autoriser la localisation** :
   - Au premier lancement, autorisez l'accès à la localisation
   - Allez dans `Paramètres > Applications > App Immobilier > Localisation`

2. **Utiliser le GPS** :
   - Appuyez sur **"GPS"** dans le menu
   - L'application affiche votre position actuelle
   - Les biens proches s'affichent sur la carte

### Fonctionnalités GPS

- **🗺️ Carte interactive** : Visualisez les biens autour de vous
- **📍 Navigation** : Itinéraire vers un bien sélectionné
- **🔍 Recherche locale** : Trouvez des biens dans un rayon défini
- **📏 Mesure de distance** : Calculez la distance jusqu'aux biens

### Note importante
L'utilisation du GPS nécessite un abonnement "Option B" pour fonctionner pleinement.

## Paiements et Abonnements

### Types d'Abonnements

#### Option A : Publication (10 000 FCFA/an)
- **Publier** des biens immobiliers
- **Nombre illimité** d'annonces
- **Photos illimitées** par annonce
- **Validité** : 1 an

#### Option B : Recherche (5 000 FCFA/an)
- **Rechercher** des biens
- **Accès GPS** et localisation
- **Filtres avancés** de recherche
- **Validité** : 1 an

### Souscrire à un Abonnement

1. **Accéder aux paiements** :
   - Appuyez sur **"Paiements"** dans le menu
   - Choisissez **"S'abonner"**

2. **Sélectionner l'option** :
   - **Option A** : Pour publier des biens
   - **Option B** : Pour rechercher avec GPS

3. **Paiement** :
   - Choisissez le montant (5 000 ou 10 000 FCFA)
   - Appuyez sur **"Payer maintenant"**
   - Sélectionnez le mode de paiement (NotchPay, Mobile Money...)

4. **Confirmation** :
   - Suivez les instructions de paiement
   - Votre abonnement est activé immédiatement après confirmation

### Historique des Paiements

1. **Consulter l'historique** :
   - Allez dans **"Paiements" > "Historique"**
   - Visualisez toutes vos transactions

2. **Informations disponibles** :
   - **Date** du paiement
   - **Montant** payé
   - **Statut** : Validé, en attente, échoué
   - **Référence** de transaction

## Profil Utilisateur

### Informations Personnelles

1. **Accéder au profil** :
   - Appuyez sur **"Profil"** dans le menu

2. **Modifier vos informations** :
   - **Nom** et prénom
   - **Email** (non modifiable)
   - **Téléphone**
   - **Photo de profil**
   - **Bio** : Description personnelle

3. **Sauvegarder** les modifications

### Paramètres de Sécurité

#### Changer le Mot de Passe

1. Appuyez sur **"Sécurité"** dans le profil
2. Appuyez sur **"Changer le mot de passe"**
3. Entrez :
   - **Mot de passe actuel**
   - **Nouveau mot de passe**
   - **Confirmation** du nouveau mot de passe
4. Appuyez sur **"Valider"**

#### Authentification à Deux Facteurs

1. Activez l'option **"2FA"** dans les paramètres de sécurité
2. Suivez les instructions pour configurer :
   - **SMS** : Code par message texte
   - **Email** : Code par email
   - **App** : Application d'authentification

### Notifications

1. **Gérer les notifications** :
   - Allez dans **"Profil > Notifications"**
   - Activez/désactivez :
     - **Nouveaux biens** dans votre zone
     - **Messages** des autres utilisateurs
     - **Mises à jour** de l'application
     - **Promotions** et offres spéciales

## Fonctionnalités Avancées

### Favoris

1. **Ajouter aux favoris** :
   - Appuyez sur l'icône **❤️** sur un bien
   - Le bien est sauvegardé dans vos favoris

2. **Consulter les favoris** :
   - Allez dans **"Profil > Mes Favoris"**
   - Accédez rapidement à vos biens préférés

### Messages

1. **Contacter un propriétaire** :
   - Sur une fiche de bien, appuyez sur **"Contacter"**
   - Envoyez un message directement

2. **Boîte de réception** :
   - Allez dans **"Messages"** dans le menu
   - Consultez et répondez à vos messages

### Partage

1. **Partager un bien** :
   - Appuyez sur l'icône de **partage** 📤
   - Choisissez la plateforme :
     - **WhatsApp**
     - **Facebook**
     - **Email**
     - **SMS**

### Mode Hors Ligne

Certaines fonctionnalités sont disponibles hors connexion :
- **Consultation des favoris**
- **Visualisation des biens consultés récemment**
- **Modification du profil**
