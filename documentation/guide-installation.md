# Guide d'Installation du Logiciel App Immobilier

## Prérequis

### Système d'exploitation supporté
- **Android** : Version 8.0 (API level 26) ou supérieure
- **iOS** : iOS 13.0 ou supérieure
- **Web** : Navigateurs modernes (Chrome, Firefox, Safari, Edge)

### Espace de stockage requis
- **Android** : 50 MB d'espace libre
- **iOS** : 50 MB d'espace libre

### Connexion Internet
- Connexion Wi-Fi ou 4G/5G requise pour le fonctionnement complet de l'application

---

## Méthodes d'Installation

### Méthode 1 : Via Expo Go (Recommandé pour tester)

1. **Installer Expo Go** sur votre smartphone :
   - **Android** : Allez sur Google Play Store, cherchez "Expo Go" et installez
   - **iOS** : Allez sur App Store, cherchez "Expo Go" et installez

2. **Scanner le QR Code** :
   - Ouvrez l'application Expo Go
   - Appuyez sur "Scanner le QR Code"
   - Scannez le QR Code fourni par le développeur

3. **Lancement** :
   - L'application se lancera automatiquement après le scan
   - Acceptez les permissions demandées

### Méthode 2 : Fichier APK (Android uniquement)

1. **Télécharger le fichier APK** :
   - Cliquez sur le lien de téléchargement fourni
   - Le fichier `app-immobilier.apk` sera téléchargé

2. **Autoriser l'installation** :
   - Allez dans `Paramètres > Sécurité` sur votre Android
   - Activez "Autoriser l'installation d'applications inconnues"

3. **Installer l'application** :
   - Ouvrez le fichier APK téléchargé
   - Suivez les instructions d'installation
   - Confirmez l'installation

4. **Premier lancement** :
   - Trouvez l'icône "App Immobilier" sur votre écran d'accueil
   - Appuyez dessus pour lancer l'application

### Méthode 3 : Web Application

1. **Accéder via navigateur** :
   - Ouvrez votre navigateur web
   - Allez à l'URL : `https://app-immobilier.expo.app`

2. **Ajouter à l'écran d'accueil** :
   - **Android** : Appuyez sur les 3 points > "Ajouter à l'écran d'accueil"
   - **iOS** : Appuyez sur l'icône de partage > "Sur l'écran d'accueil"

---

## Configuration Initiale

### Première Utilisation

1. **Création de compte** :
   - Appuyez sur "S'inscrire"
   - Remplissez vos informations (nom, email, téléphone)
   - Validez votre email

2. **Connexion** :
   - Entrez votre email et mot de passe
   - Appuyez sur "Se connecter"

3. **Permissions requises** :
   - **Localisation** : Pour les services de géolocalisation GPS
   - **Caméra** : Pour prendre des photos des biens immobiliers
   - **Stockage** : Pour sauvegarder les images

## Mises à Jour

### Mise à jour automatique
- L'application vérifie automatiquement les mises à jour au démarrage
- Une notification apparaît si une mise à jour est disponible

### Mise à jour manuelle (APK)
1. Téléchargez la nouvelle version du APK
2. Installez par-dessus l'ancienne version
3. Vos données seront conservées

## Dépannage

### Problèmes courants

**"Application ne s'installe pas"**
- Vérifiez que vous avez assez d'espace de stockage
- Assurez-vous d'avoir autorisé les installations inconnues (Android)

**"Application se ferme brutalement"**
- Redémarrez votre téléphone
- Vérifiez que votre système d'exploitation est compatible

**"Connexion impossible"**
- Vérifiez votre connexion internet
- Confirmez que vos identifiants sont corrects

## Sécurité

### Protection des données
- Vos données sont cryptées lors de la transmission
- Les mots de passe sont hashés et non stockés en clair

### Permissions
L'application demande uniquement les permissions nécessaires :
- Localisation : Pour les services GPS
- Caméra : Pour les photos des biens
- Stockage : Pour sauvegarder les images locales

---

## Désinstallation

### Android
1. Allez dans `Paramètres > Applications`
2. Cherchez "App Immobilier"
3. Appuyez sur "Désinstaller"
4. Confirmez la désinstallation

### iOS
1. Appuyez longuement sur l'icône de l'application
2. Appuyez sur "Supprimer l'application"
3. Confirmez la suppression
